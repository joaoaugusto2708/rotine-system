LIFEQUEST
PLANEJAMENTO DE DESENVOLVIMENTO POR FATIAS

OBJETIVO
Desenvolver o LifeQuest por fatias verticais orientadas às telas.

REGRA PRINCIPAL
Definir/desenhar a tela -> implementar apenas o backend necessário -> implementar o frontend -> testar -> seguir para a próxima fatia.

A infraestrutura será adicionada somente quando a funcionalidade realmente precisar.

==================================================
PRINCÍPIOS
==================================================

- Não construir todo backend antes do frontend.
- Não construir todo frontend antes do backend.
- Não adicionar infraestrutura sem necessidade real.
- Não instalar bibliotecas apenas porque podem ser úteis no futuro.
- Cada fatia deve terminar utilizável.
- Backend calcula regras de negócio.
- Frontend envia fatos.
- Manter arquitetura simples enquanto possível.
- Evoluir infraestrutura conforme a aplicação crescer.
- Preservar a arquitetura definida nos ADRs.
